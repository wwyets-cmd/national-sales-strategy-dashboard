# 全国销售策略数据看板

把当年与上年销售发/退货明细生成一个单文件、离线可打开、ECharts 内嵌的交互式 HTML 看板。

## 快速使用

```bash
python3 scripts/build_dashboard.py \
  --file26 2026销售发退货明细.htm \
  --file25 2025销售发退货明细.xlsx \
  --targets assets/targets_example.json \
  --model-overrides assets/model_overrides_example.json \
  --out 全国销售数据看板.html
```

无上年数据时加 `--skip-25`，同比区域显示 `--` 或“新增”。

## 输入要求

- 支持 `.xlsx`、`.xls`、`.csv`、WPS/Excel 导出的 `.htm/.html` 表格。
- 自动扫描前10行定位表头；WPS HTML 大表流式解析。
- 必需字段：`发/退货日期`、`客户名称`、`客户简称`、`省份`、`地级市`、`销售员`、`销货单号`、`物料描述`、`数量`、`含税本位币金额`、`大类名称`、`小类名称`。
- 金额使用 `含税本位币金额`；退货以负数自然冲减。

## 固定口径

- 不内置任何区域、全国或业务员目标；全部目标由使用者通过 `--targets` 上传。
- 目标缺失时显示“待配置”，不按0计算。
- 选中单个客户时，目标取客户所在城市目标。
- 基础五金=铰链+滑轨+反弹器。
- 反弹器严格取 `大类名称=OEM` 且 `小类名称=开门器`；`成品_开门器` 归开门器/OT。
- 功能五金=除基础五金、辅料宣传外的所有品类。
- 铰链、滑轨型号保留原始物料描述及尺寸；其他品类自动提取关键型号，可用 `--model-overrides` 修正例外。
- 安索夫新/老客户与新/老产品按上年同期是否有销售判定。

## 看板模块

顶部固定筛选器联动：年度、月份、省份、业务员、客户。模块包括KPI、月度同比、城市目标、品类饼图/柱图、基础五金、功能五金、辅料物料、客户排名展开、业务员业绩、产品型号搜索、月度分析、RFM/ABC/BCG/B2B漏斗/安索夫智能分析建议。

## 交付前检查

1. `python3 -m py_compile scripts/build_dashboard.py`
2. 用真实文件生成HTML。
3. 核对控制台的总额、品类合计、型号层合计；型号层合计应与总销售额一致。
4. 浏览器打开确认无控制台错误、筛选器联动、缺失目标显示“待配置”。
